Delivery workflow

From commit to static deployment

01

Push a source change

Website files and pipeline configuration are versioned in GitHub.

02

Trigger CodePipeline

The source stage retrieves the new revision and starts the configured pipeline.

03

Package with CodeBuild

CodeBuild reads buildspec.yml and emits the static website artifact.

04

Deploy to S3

The deployment stage publishes the artifact to the S3 website bucket.
