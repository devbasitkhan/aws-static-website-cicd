Cloud / DevOps project

Static website delivery with AWS CI/CD

A small deployment project demonstrating how source changes can move from GitHub through AWS CodePipeline and CodeBuild to an Amazon S3-hosted website.

View pipeline flow View source on GitHub

What this repository demonstrates

Source

Static HTML, CSS and JavaScript versioned in GitHub.

Build

CodeBuild reads buildspec.yml and prepares the deployment artifact.

Deploy

CodePipeline delivers the artifact to an S3 bucket configured for static website hosting.

Built as a focused AWS CI/CD engineering exercise.
