Architecture

Four components, one delivery path

The project keeps the application deliberately simple so the deployment workflow remains easy to inspect.

1. GitHubStores the website source.
2. CodePipelineOrchestrates the delivery workflow.
3. CodeBuildPackages the static artifact using the buildspec.
4. Amazon S3Hosts the deployed static assets.
Security boundary: AWS credentials do not belong in source control. Pipeline access should be granted through appropriately scoped IAM roles.
